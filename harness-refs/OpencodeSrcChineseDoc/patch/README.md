# Patch 模块新手教程

## 这是什么
Patch 模块统一处理 diff 的生成与应用，是 apply_patch、计划模式和 snapshot 的底层实现。

## 为什么需要它
让模型输出 patch 比直接写文件安全，Patch 模块还能检查路径、防止覆盖未追踪的文件。

## 关键概念
- **Diff**：描述文件改动的文本格式，通常以 @@ 行号 开头。

## 主要文件速查
- **index.ts**：统一处理 diff 生成、apply patch 以及与工具的接口。

## 原理速览
- 应用 patch 前会验证目标文件是否存在且未被忽略。
- 失败时会返回清晰的冲突描述，方便手动合并。

## 入门练习
- 使用 apply_patch 工具修改文件，观察 Patch 模块日志。

## 常见坑与调试建议
- 跨平台时注意换行符（CRLF/LF），否则 patch 可能失败。
