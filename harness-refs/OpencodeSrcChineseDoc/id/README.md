# ID 模块新手教程

## 这是什么
ID 模块生成可排序的 ID（升序或降序），供 session/message/part 等实体使用，从而无需额外索引就能按时间遍历。

## 为什么需要它
随机 UUID 难以排序，自定义 ID 还能通过前缀看出实体类型，调试更方便。

## 关键概念
- **Ascending ID**：越新的值越大，适合按时间升序排列。
- **Descending ID**：越新的值越小，适合把最新内容排在最前面。

## 主要文件速查
- **id.ts**：提供升序/降序的分布式 ID 生成器，确保 Session/Message/Part 唯一性。

## 原理速览
- ID 由时间戳 + 随机段组成，既能排序又能避免碰撞。
- 不同实体使用不同前缀（session_/message_）方便定位。

## 入门练习
- 调用 `Identifier.ascending("demo")` 多次，观察是否单调递增。

## 常见坑与调试建议
- 系统时钟错误会影响 ID 顺序，虚拟机需同步时间。
