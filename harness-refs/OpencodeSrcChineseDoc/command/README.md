# Command 模块新手教程

## 这是什么
Command 模块把固定动作（初始化、进入计划模式等）抽象为命令对象，Session 或 Agent 可以复用它们。

## 为什么需要它
使用命令比在提示词里硬编码动作更安全，也方便统计调用次数或统一调整行为。

## 关键概念
- **Command Info**：包含 id、描述、执行函数的对象。

## 主要文件速查
- **index.ts**：声明并管理可被 Session/Agent 触发的内建命令集（INIT、PLAN 等）。

## 原理速览
- SessionPrompt 在构建对话时会先插入 INIT 命令输出。
- 命令可以限制只在特定模式执行，例如 plan 专属命令。

## 入门练习
- 在 `command/index.ts` 新增一个打印消息的命令并在 Session 中调用。

## 常见坑与调试建议
- 命令失败会中断整个对话，务必捕获异常并提供友好信息。
