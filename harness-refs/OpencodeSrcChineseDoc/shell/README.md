# Shell 模块新手教程

## 这是什么
Shell 模块封装底层命令执行逻辑（工作目录、环境变量、编码、超时），供 bash 工具或 CLI 直接调用。

## 为什么需要它
统一封装可以保证输出格式一致，并在出错时提供清晰日志与错误码。

## 关键概念
- **Exit Code**：命令退出状态，0 表示成功，非 0 表示失败。

## 主要文件速查
- **shell.ts**：抽象底层 shell 执行（环境变量、工作目录、编码等）。

## 原理速览
- Shell.run 捕获 stdout/stderr 并在需要时截断。
- 支持为每个命令指定工作目录与环境变量，自动处理跨平台路径差异。

## 入门练习
- 通过 bash 工具运行 `ls` 或 `dir`，观察 Shell 模块返回值结构。

## 常见坑与调试建议
- 长时间运行的命令记得配置超时，避免卡住整个会话。
