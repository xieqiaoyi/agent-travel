# Bun 工具模块新手教程

## 这是什么
Bun 模块封装 Bun 运行时的能力（spawn、install 等），业务代码只需 import 这里的 helper 就能跨平台调用子进程。

## 为什么需要它
集中封装可以降低未来迁移成本，并避免在各处重复编写安装/执行逻辑。

## 关键概念
- **Bun**：兼容 Node.js 的新运行时，自带打包与安装能力。
- **Proc Wrapper**：把常见子进程操作包装成易用函数并附带日志。

## 主要文件速查
- **index.ts**：提供 Bun 运行时特有的工具（子进程、依赖安装等）封装。

## 原理速览
- `BunProc.install` 会把依赖装到临时目录再动态 import。
- 子进程输出会统一截断记录，防止刷屏。

## 入门练习
- 调用 `BunProc.install("@types/node")` 观察缓存目录变化。
- 让 Provider 装载尚未安装的 SDK，确认 CLI 会自动下载。

## 常见坑与调试建议
- 请确保 Bun ≥ 1.3，否则部分 API 可能缺失。
- 不要手动删除临时目录，以免并发命令报错。
