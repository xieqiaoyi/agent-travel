# PTY 模块新手教程

## 这是什么
PTY 模块封装伪终端的创建与通信，供 TUI 或远程控制功能使用，让 Web/TUI 可以看到真实 Shell 输出。

## 为什么需要它
伪终端提供交互式体验（颜色、输入），比单纯的命令输出更贴近真实终端。

## 关键概念
- **Pseudo Terminal**：用户态模拟终端设备，允许程序像操作真实终端一样发送/接收数据。

## 主要文件速查
- **index.ts**：创建和管理伪终端实例，供 TUI/远程执行命令使用。

## 原理速览
- Unix 与 Windows 使用不同实现（pty vs ConPTY），封装里统一处理。
- PTY 输出会写入 Bus/SSE，前端实时显示。

## 入门练习
- 运行 `opencode tui attach`，观察 PTY 对命令输出的处理方式。

## 常见坑与调试建议
- Windows 旧版本可能需要 winpty 才能正常工作。
